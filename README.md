# Content Pipeline — контент-конвейер под ключ

Система, которая ведёт контент от идеи до опубликованного поста: собирает тренды, пишет тексты,
рисует карусели, собирает PDF-лид-магниты, монтирует Reels и публикует всё **только после вашего
«Одобрить»** в Telegram.

Управление — из одной группы в Telegram. Никаких панелей и логинов в непонятные сервисы: пишете
задачу в топик нужного агента, получаете готовый материал карточкой с кнопками
«Одобрить / Отклонить / Правка».

---

## Что система делает

| Агент | Что делает | Где живёт |
|---|---|---|
| **Продюсер** | принимает цель, раздаёт задачи остальным, показывает статус | сервер |
| **Разведчик** | собирает посты конкурентов и выделяет темы недели | сервер |
| **Сценарист** | посты в Telegram, тексты каруселей, сценарии Reels, посты в Threads | сервер |
| **Дизайнер** | карусели и обложки — готовые картинки, а не описание | сервер |
| **Презентатор** | три PDF-лид-магнита для инста-воронки | сервер |
| **Издатель** | очередь согласования, кнопки, публикация после «ок» | сервер |
| **Видео** | монтаж ваших реальных клипов в Reels | ваш ноутбук |
| **Аналитик** | еженедельный разбор: что сделано, где затык, что менять | сервер |

**Куда публикует:** Telegram-канал, Instagram (карусели, обложки, Reels), Threads.
**Инста-воронка:** человек пишет в директ ключевое слово → ManyChat отдаёт ссылку на нужный PDF.

## Чего система НЕ делает (важно понимать сразу)

- **Не публикует без вас.** Наружу уходит только то, что вы одобрили кнопкой.
- **Не постит в чужие аккаунты** — только в ваши собственные.
- **Не монтирует видео на сервере.** Монтаж идёт на вашем ноутбуке: сырое видео физически не
  проходит через Telegram (лимит 20 МБ на файл). Готовый ролик сам уезжает на сервер в очередь.
- **Не настраивает воронку в ManyChat полностью автоматически.** Ссылки на PDF система обновляет
  сама, а сообщение с тремя кнопками собирается в интерфейсе ManyChat один раз руками — по готовой
  инструкции, которую система же и печатает.
- **Не выдумывает факты о вашем бизнесе.** Пока не заполнен «мозг бренда» (папка `brand-brain/`),
  тексты будут обезличенными. Это не поломка — это ожидаемо.

## С чего начать

**Откройте [НАЧНИ-ОТСЮДА.md](НАЧНИ-ОТСЮДА.md).** Там простым языком: что уже работает, что вы
делаете каждый день и что осталось подключить. Начинать нужно именно с него — этот README даёт
общую картину, а тот файл говорит, что делать руками.

Это исходный код для самостоятельной установки. Сервер, боты и Telegram-канал
настраиваются в ваших аккаунтах по [инструкции установки](deploy/vps-setup.md).
Документы ниже описывают настройку и использование:

| Документ | Когда открывать |
|---|---|
| [НАЧНИ-ОТСЮДА.md](НАЧНИ-ОТСЮДА.md) | **первым**, сразу |
| [deploy/go-live.md](deploy/go-live.md) | протокол приёмки: чек-лист, что реально проверено |
| [deploy/handover.md](deploy/handover.md) | эксплуатация: что ломается чаще всего |
| [deploy/README.md](deploy/README.md) | какие аккаунты и оплаты оформляются на вас |
| [deploy/vps-setup.md](deploy/vps-setup.md) | установка с нуля и перенос на другой сервер |

Единственное, что действительно ждёт вас: **заполнить `brand-brain/`** — голос бренда, аудитория,
продукты, стоп-слова. Это единственное, что даёт контенту ваше лицо.

## Что здесь лежит

```
НАЧНИ-ОТСЮДА.md    что уже работает и что делать вам  ← начните отсюда
CLAUDE.md          устройство системы и правила — это читает Claude Code на вашей машине
README.md          этот файл
deploy/            установка на сервер, приёмка, эксплуатация
agents/            по файлу на агента: что он умеет и где его границы
brand-brain/       «мозг бренда» — заполняете вы
specs/             как устроен каждый модуль и почему сделано именно так
dispatcher/        код: боты, очередь, публикация, тренды, воронка, аналитика
render/            сборка картинок и PDF
video/             ставится на ваш ноутбук: монтаж и заливка роликов
trends/            кого читает Разведчик (список аккаунтов и хэштегов)
manychat/          три темы инста-воронки
```

## Файлы, которые вы меняете сами (код трогать не нужно)

| Хочу поменять | Файл |
|---|---|
| Голос бренда, аудиторию, стоп-слова | `brand-brain/` |

## Если что-то непонятно

Вся система описана внутри этой папки — специально так, чтобы в ней мог разобраться и человек, и
Claude Code на вашем компьютере. Откройте эту папку в Claude Code и спросите словами: «как здесь
устроена публикация в Instagram?» — он прочитает `CLAUDE.md` и `specs/` и ответит.

## Приватные данные

В публичной версии находятся только исходники, документация, пустые шаблоны бренда и тестовые
данные. Настройки с доступами создавайте локально из `dispatcher/.env.example` и
`video/vps.env.example`; рабочие `.env`, базы, логи, браузерные профили и материалы исключены
через `.gitignore`.

Перед каждым коммитом проверяйте состав изменений. Заполненные файлы `brand-brain/*.md`
уже отслеживаются Git: `.gitignore` не скрывает их изменения. Личные данные, заметки,
коммерческие материалы и реальные доступы в публичный репозиторий не добавляйте.
Статусы прошлых проверок в спецификациях относятся к тестовой установке; свою установку
проверяйте отдельно по `deploy/go-live.md`.
