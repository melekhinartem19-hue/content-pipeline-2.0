# Хендовер: что передаётся, как это эксплуатировать и где границы

Документ для клиента. После го-лайва система принадлежит ему целиком: код, доступы, данные.

## Что передаётся

| Что | Где лежит |
|---|---|
| Код продукта | `/opt/content-pipeline` на VPS + копия папкой у клиента |
| Секреты установки | `/opt/content-pipeline/dispatcher/.env` — **только там** |
| База | `/opt/content-pipeline/dispatcher/data/pipeline.sqlite` |
| Готовые материалы | `/var/www/content-pipeline` (кадры, PDF) |
| Владение ботами, группой, каналом | аккаунт клиента (см. [telegram-transfer.md](telegram-transfer.md)) |
| Документация | `CLAUDE.md` (устройство и правила), `specs/` (по модулям), `deploy/` (эта папка) |

Всё написано так, чтобы Claude Code на машине клиента прочитал репозиторий и разобрался без нас:
каждый агент — отдельный файл в `agents/`, каждый модуль — спека в `specs/`, ничего не спрятано
в скрытых папках.

## Что клиент меняет сам, не трогая код

| Хочу поменять | Файл |
|---|---|
| Голос бренда, аудиторию, стоп-слова | `brand-brain/` |
| Подкинуть агентам идею, референс, фото, файл | бот «Мозг бренда» в его топике → `brand-brain/09-inbox.md` и `materials/` |
| Цвета и шрифт слайдов | `brand-brain/08-visual-style.md` |
| Кого читает Разведчик | `trends/sources.json` |
| Три темы воронки и тексты ответов | `manychat/funnel.json` |
| Поведение агента | соответствующий файл в `agents/` |
| Доступ ноутбука к серверу (видео) | `video/vps.env` на ноутбуке |

После правки `.env` — рестарт сервиса. Остальные файлы читаются на каждом запуске.

## Эксплуатация

```bash
systemctl status content-pipeline          # жив ли
journalctl -u content-pipeline -f          # что происходит прямо сейчас
sudo systemctl restart content-pipeline    # после правки .env
```

**Бэкап базы** (в ней очередь, задачи, история публикаций и ссылки воронки):

```bash
sudo apt-get install -y sqlite3
sudo -u pipeline sqlite3 /opt/content-pipeline/dispatcher/data/pipeline.sqlite \
  ".backup '/opt/content-pipeline/backup-$(date +%F).sqlite'"
```

`.backup` снимается на работающем сервисе безопасно; простое копирование файла — только при
остановленном. Материалы в `/var/www/content-pipeline` бэкапить отдельно: PDF пересобираются
командой `/пдф`, но ссылки на них уже разосланы людям.

**`brand-brain/` бэкапить тоже** — ни в базе, ни в git этих данных нет: заполненные слоты,
«Входящие» и файлы, которые клиент прислал боту «Мозг бренда»:

```bash
sudo tar czf /opt/content-pipeline/brand-brain-$(date +%F).tgz -C /opt/content-pipeline brand-brain
```

**Проверить настройку публикации** (после смены токенов Meta — они истекают):

```bash
cd /opt/content-pipeline/dispatcher && npm run check:meta
```

Ничего не публикует: показывает, видна ли статика снаружи, жив ли токен каждой площадки и есть ли
право публиковать. То же самое из Telegram — «/проверка» в топике Издателя.

**Команды на VPS, которые дёргает ноутбук по SSH** (руками их запускать не нужно):

```bash
npm run video:jobs           # что ждёт монтажа (video/pull-jobs.sh с ноутбука)
npm run ingest:video -- ...  # принять готовый ролик (video/upload.sh с ноутбука)
```

**Обновление кода:** заменить папку (кроме `.env`, `data/` и **`brand-brain/`**), `npm install` в
`dispatcher/` и `render/`, рестарт. Миграции базы применяются сами при старте. `brand-brain/` не
трогать обязательно: на сервере там уже слоты и «Входящие» клиента, а в новой папке — пустые
шаблоны, и копирование поверх молча сотрёт всё, что клиент туда написал и прислал.

## Что ломается чаще всего

| Симптом | Причина | Что делать |
|---|---|---|
| Агенты молчат, боты живы | слетел логин Claude Code | `sudo -u pipeline bash -lc 'claude'` — войти заново |
| Пост не уходит в канал | бот Издателя не админ канала | вернуть права админа с публикацией |
| Слайды квадратиками | нет кириллических шрифтов | `apt-get install fonts-dejavu fonts-noto-core` |
| IG не публикует карусель | статика недоступна снаружи или не HTTPS | проверить ссылку с телефона |
| Воронка отдаёт 404 | сменился `PUBLIC_BASE_URL` | `/воронка` покажет расхождение → `/воронка синх` |
| `/тренды` отказывается | суточный лимит (защита от счёта Apify) | завтра или осознанно обойти |
| Ролик с ноутбука не принимается | не настроена публичная статика или файл тяжелее лимита | проверить `PUBLIC_*`, пережать ролик (`VIDEO_MAX_MB`) |
| «Правка» на ролике отвечает отказом | так и задумано: монтажной на VPS нет | перемонтировать на ноуте и залить заново |
| В отчёте Аналитика нет цифр площадок | метрики выключены или нет прав `*_manage_insights` | включить `ANALYTICS_INSIGHTS=1` и права в Meta |

## Границы: что НЕ входит

- **Видео-монтаж.** Ставится отдельно на ноутбук клиента (локальный Claude Code + видео-скиллы),
  инструкция — [../video/README.md](../video/README.md). Сырое видео не проходит через
  Telegram-бота (лимит Bot API 20 МБ), поэтому монтаж локальный. В VPS-деплой входит только приём
  готового ролика и очередь заявок на монтаж.
- **Автомонтаж — это не «монтаж без человека».** Заявка доезжает до ноутбука сама, но клипы
  выбирает и собирает человек.
- **Метрики площадок у Аналитика — по желанию клиента.** Отчёт работает и без них, по фактам
  собственной базы; инсайтам Instagram/Threads нужны отдельные права в его же приложении.
- **Автоматическая настройка воронки.** API ManyChat не умеет создавать флоу — сообщение с тремя
  кнопками и триггеры заводятся в UI один раз руками, по карточке `/воронка настройка`.
- **Публикация в чужие аккаунты.** Meta App Review не проходим: публикация только в собственные
  аккаунты клиента.

## Что оплачивает клиент

VPS · домен · Claude Pro (на нём работают все агенты) · Apify (каждый прогон трендов платный) ·
ManyChat Pro (без него нет API воронки) · Meta-приложения (бесплатны, но требуют его аккаунтов).
Все сервисы оформлены **на клиента** — исполнитель не платёжный посредник.

## Первые дни: что сделать клиенту

1. Заполнить `brand-brain/` — до этого тексты будут обезличенными.
2. Вписать в `trends/sources.json` 10–20 аккаунтов своей ниши.
3. Прогнать полный круг: `/тренды` → задача Сценаристу → карточка → «Одобрить» → пост.
4. Собрать флоу воронки в ManyChat и проверить все три ключа из директа.
