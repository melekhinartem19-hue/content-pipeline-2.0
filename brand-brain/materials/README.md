# Материалы бренда (`brand-brain/materials/`)

Сюда бот **«Мозг бренда»** складывает файлы, которые клиент прислал в свой топик: фото, видео,
документы, аудио. Имя файла — `ГГГГММДД-ЧЧММСС-<id сообщения>-<исходное имя>`, поэтому новые
файлы никогда не затирают старые.

У каждого файла есть строка в [../09-inbox.md](../09-inbox.md): вид, путь и подпись клиента.

## Что важно знать

- **Агенты сами файлы не видят.** Агент — это один проход `claude -p` с текстовым промптом:
  картинку, видео или PDF он не открывает. Всё, что он знает о файле, — это подпись во
  «Входящих». Файл без подписи для агента — только имя.
- **До 20 МБ.** Тяжелее Telegram боту не отдаёт (ограничение Bot API). Исходники видео живут на
  ноуте клиента, где идёт монтаж.
- **В git эта папка не идёт** — кроме этого README. Это данные клиента, а не код.
- Файлы можно смело удалять руками, если они больше не нужны; строку во «Входящих» тогда тоже
  стоит удалить, чтобы агенты не ссылались на то, чего нет.
