# Мозг бренда (`brand-brain/`)

Это **пустой размеченный шаблон**. Его наполняет **клиент** — своими фактами о бренде. Каждый
агент конвейера читает этот каталог **перед каждой задачей**, поэтому чем полнее слоты, тем
персональнее и точнее контент. Пока слоты пусты — контент будет обезличенным (это нормально и
ожидаемо на старте).

## Как заполнять

- Правь файлы-слоты ниже прямо здесь, обычным текстом (markdown).
- Строки в `<!-- ... -->` — это подсказки для тебя; их можно оставить или удалить, агент их
  не видит как содержимое.
- Пиши факты, а не воду: агенты не должны ничего выдумывать сверх написанного здесь.
- Заполнять можно постепенно — начни с `00-brand.md`, `01-audience.md`, `02-tone-of-voice.md`.

> Слот `09-inbox.md` руками заполнять не нужно — туда пишет бот **«Мозг бренда»** (T18): идеи,
> пересланные посты, подписи к фото/видео/файлам. Сами файлы лежат в [materials/](materials/).
> Агенты читают «Входящие» вместе с остальными слотами. Когда записей станет много — перенесите
> главное в слоты 00–08 и удалите из «Входящих»: слот читается целиком перед каждой задачей.
> Подробности — [../specs/brand-inbox.md](../specs/brand-inbox.md).

> Слот `08-visual-style.md` особенный: его читают и агенты, и **код рендера**
> ([../render/theme.js](../render/theme.js)) — поэтому строки «Фон:», «Текст:», «Акцент:»,
> «Шрифт:», «Подпись:» имеют фиксированный вид. Пусто — рендер берёт нейтральную тему.

> Технически чтение слотов реализовано в
> [../dispatcher/src/agent.js](../dispatcher/src/agent.js) (`loadBrandBrain`). Файл `README.md`
> агенты НЕ читают — только слоты `NN-*.md`.
