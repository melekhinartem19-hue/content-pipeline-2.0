# trends/ — что смотрит Разведчик

Здесь лежит **список источников** для сбора трендов: чьи посты в Instagram и Threads тянуть,
сколько и как часто. Сам сбор делает **Apify** — облачный сервис-скрапер: мы не логинимся ни в
какой аккаунт, актор Apify ходит в соцсети сам.

> Секретов в этой папке нет и быть не должно. Токен Apify — только в `dispatcher/.env`.

## Что вводит клиент при установке (3 вещи)

1. **Токен Apify** → в `dispatcher/.env`, строка `APIFY_TOKEN=`.
   Взять: apify.com → Settings → Integrations → API token.
2. **Id акторов** — какими акторами из [Apify Store](https://apify.com/store) собирать.
   Пишутся в `trends/sources.json` (поле `actor`) или в `.env` (`APIFY_ACTOR_IG`,
   `APIFY_ACTOR_THREADS` — они перебивают файл).
3. **Свои аккаунты и хэштеги** → `trends/sources.json`, поля `accounts` и `hashtags`.

```bash
cp trends/sources.example.json trends/sources.json   # и отредактировать под себя
```

Без `sources.json` сбор честно скажет «источники не настроены» и ничего не потратит.

## Как устроен файл источников

| Поле | Что значит |
|---|---|
| `limits.runsPerDay` | сколько прогонов в сутки разрешено (по умолчанию 1 — этого хватает) |
| `limits.postsPerSource` | сколько постов тянуть с одного аккаунта/хэштега |
| `limits.maxPostsPerRun` | жёсткий потолок на прогон — страховка от счёта за Apify |
| `platforms.<ig\|threads>.enabled` | собирать ли эту площадку |
| `platforms.<…>.actor` | id актора Apify, например `apify/instagram-scraper` |
| `platforms.<…>.accounts` | аккаунты без `@` |
| `platforms.<…>.hashtags` | хэштеги без `#` |
| `platforms.<…>.request` | как класть цели во вход актора (см. ниже) |
| `platforms.<…>.map` | как называются поля в выдаче актора (обычно можно не трогать) |

### `request` — почему это настраивается

У каждого актора в Apify **свой формат входа**. Один ждёт ссылки в поле `directUrls`, другой — в
`urls`, третий — в `startUrls`. Поэтому имя поля не зашито в код, а лежит здесь:

```json
"request": { "urlsField": "directUrls", "limitField": "resultsLimit", "extra": { "resultsType": "posts" } }
```

Ссылки диспетчер строит сам: аккаунт → `https://www.instagram.com/<аккаунт>/`,
хэштег → `https://www.instagram.com/explore/tags/<хэштег>/`. Если актору нужны другие ссылки —
переопредели их в `urlTemplates` (см. `specs/trends-apify.md`).

### `map` — если актор называет поля по-своему

По умолчанию диспетчер сам узнаёт типовые имена (`url`, `caption`, `likesCount`, `ownerUsername`,
`timestamp` и их синонимы). Если актор отдаёт что-то нестандартное — укажи явно:

```json
"map": { "text": ["postText"], "likes": ["stats.likes"], "author": ["user.handle"] }
```

## Как запускается сбор

- Вручную: написать **`/тренды`** в топик Разведчика (или в личку его боту).
- По расписанию: если в `.env` задан `TRENDS_AT=09:00`, диспетчер сам сделает один прогон в сутки.
- Повторный прогон в тот же день отклоняется лимитом; обойти осознанно — `/тренды сейчас`.

Собранные посты дедуплицируются по ссылке: то, что уже видели, второй раз Разведчику не уходит
и второй раз не оплачивается вниманием. Результат — отчёт с темами в топике Разведчика.

## Смена актора не ломает код

Актор в Apify Store может подорожать, сломаться или исчезнуть. План действий: выбрать другой актор,
вписать его id в `actor`, при необходимости поправить `request` и `map`. Код диспетчера не трогается.

Подробности механики — [../specs/trends-apify.md](../specs/trends-apify.md).
