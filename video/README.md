# `video/` — монтаж на ноуте клиента (ставится отдельно от VPS)

Вторая половина двухмозговой архитектуры. На VPS живёт всё, что работает круглосуточно: тексты,
картинки, PDF, согласование, публикация. **Монтаж живёт здесь — на ноутбуке клиента**, и запускается
по требованию.

> Почему не на сервере: Telegram Bot API качает файлы только до 20 МБ (правило 5 в
> [../CLAUDE.md](../CLAUDE.md)), поэтому сырой материал на VPS не попадает вообще. Плюс монтаж —
> это тяжёлый локальный процесс, которому нужны сами клипы, а они лежат у клиента.

```
Ноут клиента                                   VPS
─────────────────────────────────────────      ─────────────────────────────────
1. заявки на монтаж  ◀── pull-jobs.sh ────────  одобренный сценарий Reels
2. локальный Claude Code + скиллы HyperFrames
   монтирует реальные клипы → лёгкий MP4
3. upload.sh ─── scp + ssh ingest:video ─────▶  ролик в публичную статику
                                                карточка в топике Издателя
4.                                              «Одобрить» → Reels в Instagram
```

Сырое видео не проходит через Telegram ни в одну сторону. Наружу VPS не открывает ни одного
порта: и заявки, и заливка идут по SSH тем же ключом, которым клиент заходит на сервер.

---

## Установка на ноут (один раз)

### 1. Claude Code и скиллы

Нужен **Claude Code с той же Pro-подпиской**, что и на VPS (весь интеллект — только через него,
правило 1 в `CLAUDE.md`). Скиллы ставятся **все шесть сразу** — поодиночке они бесполезны, потому
что `hyperframes` маршрутизирует задачу в остальные:

| Скилл | Зачем |
|---|---|
| `hyperframes` | **обязательная точка входа** в любую видео-задачу |
| `hyperframes-cli` | сборка и рендер композиций из командной строки |
| `motion-graphics` | титры, плашки, инфографика, лого-стинг |
| `embedded-captions` | субтитры и «залипающие» подписи по речи |
| `general-video` | длинные и многосценовые ролики |
| `remotion-to-hyperframes` | если у клиента (или его подрядчика) уже есть Remotion-композиции — переносим исходники, а не пересобираем |

### 2. Доступ к VPS

```bash
ssh-keygen -t ed25519 -C "video-laptop"          # если ключа ещё нет
ssh-copy-id pipeline@<адрес VPS>                  # положить публичный ключ на сервер
ssh pipeline@<адрес VPS> 'echo связь есть'
```

### 3. Настройки заливки

```bash
cp video/vps.env.example video/vps.env            # адрес VPS, пользователь, пути
```

Файл `vps.env` — локальный, в git не коммитится (там адрес сервера клиента).

## Как этим пользоваться

### Шаг 1. Забрать заявки на монтаж

Заявка появляется сама, когда владелец одобряет сценарий Reels от Сценариста (T16): диспетчер
кладёт её в очередь заявок и пишет в топик Видео. Ноут забирает список сам:

```bash
./video/pull-jobs.sh              # что ждёт монтажа (человекочитаемо)
./video/pull-jobs.sh --json       # то же в JSON — это и читает локальный Claude Code
```

Заявок нет — значит монтировать нечего; можно смонтировать и без заявки, вручную.

### Шаг 2. Смонтировать

Открыть Claude Code в папке проекта на ноуте и дать задачу словами, приложив клипы. Точка входа
всегда одна:

```
/hyperframes смонтируй Reels по сценарию из заявки #12, клипы в ~/Movies/съёмка-08-09
```

Требования к результату (их держит скилл, но проверять стоит): вертикаль 1080×1920, MP4 (H.264 +
AAC), до 90 секунд, **лёгкий файл** — потолок приёма на VPS 300 МБ (`VIDEO_MAX_MB`).

### Шаг 3. Залить в очередь согласования

```bash
./video/upload.sh out/reels.mp4 --caption-file caption.txt --title "Ошибки на запуске" --job 12
```

На Windows то же самое:

```powershell
./video/upload.ps1 out/reels.mp4 -CaptionFile caption.txt -Title "Ошибки на запуске" -Job 12
```

Что произойдёт: файл уедет на VPS, ляжет в публичную статику, встанет в очередь согласования и
появится карточкой с кнопками в топике Издателя — со **ссылкой на ролик**, чтобы владелец
посмотрел его до решения. `--job` закрывает заявку на монтаж.

### Шаг 4. Публикация

Владелец жмёт «Одобрить» в Telegram → ролик уходит в Instagram как Reels (T12). Ничего
дополнительно делать не нужно, ноут в этот момент может быть выключен.

## Границы (не обещать клиенту иного)

- **Правка ролика кнопкой «Правка» не работает.** На VPS нет ни исходников, ни монтажной — там
  лежит только готовый файл. Диспетчер честно отвечает: перемонтируй на ноуте и залей заново.
- **Автомонтаж не значит «без человека».** Заявка создаётся автоматически, а монтаж запускает
  человек на ноуте: сборка идёт из реальных клипов, которые надо выбрать.
- **Ноут не обязан быть включён** — VPS работает без него. Не работает без ноута только видео.
- **Заливка — только по SSH.** Диспетчер не слушает входящих соединений: ни портов, ни вебхуков.
