# Карта проекта — Content Pipeline

Контент-конвейер «под ключ» для агентства: 7 агентов в Telegram, тренды, генерация
постов/каруселей/сценариев, инста-воронка с PDF, монтаж видео, публикация после согласования.
Собираем мы → разово деплоим на VPS клиента → передаём.

> Первоисточник правил и архитектуры — [../../CLAUDE.md](../../CLAUDE.md). Здесь — карта работ.

---

## Двухмозговая архитектура

```
┌──────────────────────── VPS (always-on, аккаунты клиента) ───────────────────────┐
│  Node-диспетчер («тупая труба»)                                                   │
│    ├── 6 Telegram-ботов ─ общая форум-группа (топик на агента) + личка 1:1        │
│    ├── SQLite (слой доступа абстрагирован → миграция на Postgres)                 │
│    ├── очередь согласования + контент-календарь                                   │
│    └── Nginx-статика (PDF, ссылки для ManyChat)                                    │
│  Интеллект ТОЛЬКО через `claude -p "..."` (Pro-подписка). Node ≠ Anthropic API.   │
│  Тренды · генерация текста/картинок/PDF · согласование · публикация TG/IG/Threads │
└───────────────────────────────────▲──────────────────────────────────────────────┘
                                     │ автозалив готового лёгкого Reels в очередь
┌────────────────────── Ноут клиента (по требованию) ───────────────────────────────┐
│  Локальный Claude Code: скиллы motion / embedded-captions / general-video          │
│  Монтаж реального материала. НЕ часть VPS-деплоя, ставится отдельно.               │
└────────────────────────────────────────────────────────────────────────────────────┘
```

## Правила, зашитые в критерии тикетов (нарушать нельзя)

1. Интеллект — только `claude -p`, Node никогда не ходит в Anthropic API напрямую.
2. Meta App Review не проходим — публикация только в аккаунты клиента, Graph API dev-mode.
3. PDF в IG-DM невозможен → ManyChat отдаёт **ссылку** на Nginx-статику или увод в Telegram.
4. Тренды — через **Apify** (решение клиента 07.09.2026): актор ходит в соцсети сам, мы не
   логинимся. 1 прогон/день остаётся, но как страховка от счёта за Apify. Вариант C (логин
   основным аккаунтом) — резерв, не реализован.
5. TG Bot API качает файлы до 20 МБ → сырое видео не через бота, монтаж локальный.
6. 3 отдельных согласования по площадкам (TG / IG / Threads) — не объединять.
7. Все сервисы — на аккаунтах клиента; секреты только в `.env`, в git не коммитить.
