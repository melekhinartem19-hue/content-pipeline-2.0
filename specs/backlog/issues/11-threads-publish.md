# 11 — Публикация в Threads (только текст), отдельное согласование

**What to build:** Одобренный текст публикуется в Threads клиента через Graph API в dev-mode (клиент = админ/тестер приложения, без прав, требующих App Review). Threads — только текст, поэтому это отдельный трек согласования, не объединённый с TG и IG.

**Blocked by:** 06 — Сценарист; 07 — Очередь согласования + кнопки.

**Status:** done (база) — spec: [../../ig-threads-publish.md](../../ig-threads-publish.md). Оффлайн-прогон зелёный (`npm run smoke`: `smoke-ig-threads`). **Живая публикация возможна только на аккаунте клиента** — нужны его Threads-приложение и токен; порядок проверки на деплое описан в спеке.

- [x] Отдельный трек согласования именно для Threads — `platform = 'threads'` у элемента очереди (`kind: threads_post`), своя карточка, своё решение владельца; с TG и IG не смешивается
- [x] Публикация через Graph API dev-mode, без прав, требующих ревью — `graph.threads.net/{user}/threads` → `/threads_publish`, права `threads_basic` + `threads_content_publish`
- [x] Только одобренный элемент уходит в Threads; статус обновляется — проверка статуса внутри `publishItem`; `published` + `published_ref`, ошибка → `publish_failed` с причиной и возможностью повтора
- [x] Креды Meta-app только в `.env` — `THREADS_USER_ID`, `THREADS_ACCESS_TOKEN`
- [x] Демо: текст → согласование → пост в Threads — оффлайн-эквивалент в `smoke-ig-threads.mjs` (шаги API, лимит, ошибки Meta); живьём на аккаунте клиента, с `PUBLISH_DRY_RUN=1` как безопасной репетицией
- [x] Короткий spec Threads-публикации положен в `specs/` — [specs/ig-threads-publish.md](../../ig-threads-publish.md)

**Гоча настройки, ловящая почти всех:** у Threads **свой API и свой токен** — хост `graph.threads.net`, отдельное приложение, права `threads_*`. Токен от Instagram здесь не работает.

**Решение по лимиту:** пост длиннее 500 знаков **не режется молча** — публикация отклоняется с причиной, текст сокращается через «Правку» и одобряется заново. Урезанный пост — это уже не то, что одобрил владелец.

**Граница:** картинки Threads технически умеет, но здесь публикуется только текст (CLAUDE.md, правило 6). Медийный Threads — отдельный формат и отдельное согласование, а не флажок.

**Что доделано в текстах агентов:** Сценарист теперь умеет отдавать `threads_post` — без этого труба была готова, а входа в неё не было.
