# 18 — «Мозг бренда»: бот-приёмник идей и материалов клиента

**What to build:** ещё один Telegram-бот в общей группе — «Мозг бренда». Через него клиент сам
пополняет brand-brain: пишет идеи, пересылает понравившиеся посты, кидает фото, видео и файлы.
Всё присланное должно оказаться там, откуда агенты читают контекст перед каждой задачей.

**Blocked by:** 04 — контракт агента + brand-brain; 03 — боты и роутер форум-группы.

**Status:** поднят на VPS (10.09.2026) — текстовая идея проверена вживую; фото/файлы/альбом
проверит владелец вместе с клиентом

- [x] Текст → запись с датой в слот `brand-brain/09-inbox.md` (решение владельца: копить как есть, без `claude -p`)
- [x] Пересланный пост → «референс» с пометкой источника
- [x] Фото/видео/аудио/документы до 20 МБ → `brand-brain/materials/` + строка каталога с подписью
- [x] Альбом → один ответ на весь альбом; тяжелее 20 МБ и голосовые — честный отказ с объяснением
- [x] Агенты видят «Входящие» без изменений в контракте (`loadBrandBrain` читает все `NN-*.md`)
- [x] Доступ — тем же `OWNER_IDS`, что и остальные боты (текст и файлы)
- [x] Спека в `specs/`, смоук в `npm run smoke`

**Как сделано.** Модуль `dispatcher/src/brain/inbox.js` (хранилище, скачивание, тексты ответов),
проводка в `src/index.js`, бот `brain` в реестре с `agent: null`. Spec:
[../../brand-inbox.md](../../brand-inbox.md). Оффлайн зелено (`smoke-brain`, всего 23 смоука).
