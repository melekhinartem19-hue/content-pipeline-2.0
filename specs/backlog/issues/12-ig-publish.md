# 12 — Публикация в IG (карусель + Reels), отдельное согласование

**What to build:** Одобренная IG-карусель/Reels публикуется в Instagram клиента через Graph API в dev-mode. У IG свой формат и свой отдельный трек согласования — не объединять с TG и Threads (3 отдельных согласования по площадкам).

**Blocked by:** 07 — Очередь согласования + кнопки; 10 — Дизайнер.

**Status:** done (база) — spec: [../../ig-threads-publish.md](../../ig-threads-publish.md). Оффлайн-прогон зелёный (`npm run smoke`: `smoke-ig-threads`). **Живая публикация возможна только на бизнес-аккаунте клиента** — нужны его Meta-приложение, IG Business и Nginx-статика; порядок проверки на деплое описан в спеке.

- [x] Отдельный трек согласования именно для IG — `platform = 'ig'` (`carousel_spec` / `cover_spec` / `reels_script`), своя карточка, своё решение владельца
- [x] Публикация через Graph API dev-mode, без прав, требующих App Review — контейнеры → `media_publish`, права `instagram_basic` + `instagram_content_publish`
- [x] Публикуются только собственные аккаунты клиента; только одобренный элемент — проверка статуса внутри `publishItem`, обойти мимо кнопки нельзя
- [x] Учтён формат IG — карусель 2–10 кадров из PNG Дизайнера (T10), один кадр = обычный пост, 11-й IG не примет; Reels публикуется по `meta.video_url` с ожиданием обработки видео
- [x] Демо: карусель → согласование → пост в IG — оффлайн-эквивалент в `smoke-ig-threads.mjs`; живьём на аккаунте клиента, с `PUBLISH_DRY_RUN=1` как репетицией
- [x] Короткий spec IG-публикации положен в `specs/` — [specs/ig-threads-publish.md](../../ig-threads-publish.md)

**Гоча, определившая архитектуру: Instagram НЕ принимает файл.** Он принимает `image_url` и скачивает картинку своими серверами. Локальные PNG из `data/renders/` для Meta не существуют — поэтому перед публикацией кадры копируются в веб-корень (`PUBLIC_DIR`) и уходят ссылками (`PUBLIC_BASE_URL`, только https). Без этих двух переменных IG-публикация невозможна в принципе.

**Гоча БД:** id поста в IG — 17–18 цифр, в JS-число такое не помещается (2^53) и тихо теряет последние цифры. Добавлена миграция `006_publish_refs` с `published_ref TEXT`.

**Решение по подписи:** подпись берётся из `meta.caption` ответа агента, а НЕ из `item.content` — content у карусели это спецификация слайдов Дизайнера. Дизайнер теперь отдаёт `caption` в META; если поля нет, пост уходит без подписи и об этом говорится в топике.

**Граница честности:** `reels_script` без готового ролика публикацию не проходит — сценарий это не видео. Ролик монтируется на ноуте клиента (T15) и приезжает публичной ссылкой в `meta.video_url`.

**Эксплуатация:** кадры в `PUBLIC_DIR/queue-<id>/` не чистятся — опубликованный пост продолжает на них ссылаться. Уборка старого — вопрос T17, не публикации.
