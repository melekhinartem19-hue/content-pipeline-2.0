# 19 — Публикация в IG/Threads живым браузером (вариант C)

**What to build:** второй путь публикации в Instagram и Threads — диспетчер заходит в аккаунт
клиента как человек и постит через веб-интерфейс, вместо Graph API. Причина — не поломка API, а
трудоёмкость настройки Meta-приложения на стороне клиента (решение владельца 15.09.2026).

**Blocked by:** 12 — публикация в Instagram через Graph API (её таблица `PLATFORMS` и контракт
результата переиспользуются целиком); 10 — рендер кадров (их и загружаем).

**Status:** сделано по коду, **живьём не проверено ничего** — селекторы проверяются только на
аккаунте клиента.

- [x] Постоянный профиль Chromium: вход один раз, сессия переживает перезапуск и перезагрузку
- [x] Вход в Instagram + проверка/2FA: код спрашивается у человека, обхода нет
- [x] Threads входит аккаунтом Instagram — свой токен и своё приложение не нужны
- [x] Публикация: карусель 2–10 кадров, одиночное фото, Reels файлом с диска
- [x] Публикация в Threads: только текст (правило 6 — не превращать текстовый пост в медийный)
- [x] Переключатель `IG_MODE=api|browser`, оба пути остаются в коде
- [x] `PUBLISH_DRY_RUN=1` работает и здесь: план печатается, браузер не запускается
- [x] `npm run ig:login` — разовый вход из консоли VPS, код вводится в консоль
- [x] «/вход» и «/вход статус» в топике Издателя; код подтверждения — карточкой + реплаем
- [x] Спека в `specs/`, смоук в `npm run smoke`
- [ ] **Живой прогон на аккаунте клиента** — вход, карусель, Reels, пост в Threads

**Как сделано.** Модуль `dispatcher/src/publish/browser/`: `selectors.js` (все селекторы в одном
месте), `session.js` (профиль, вход, проверка), `instagram.js` и `threads.js` (публикация),
`index.js` (точка входа для `PLATFORMS`), `login-command.js` («/вход» и приём кода). Проводка —
в `src/publish/index.js` (пара `ready`/`send` у площадок) и `src/index.js` (команда и реплай).
Spec: [../../ig-browser-publish.md](../../ig-browser-publish.md). Оффлайн зелено
(`smoke-browser`, всего 25 смоуков).

**Чем платим.** Автоматизация веб-интерфейса нарушает правила Instagram, и риск несёт аккаунт
клиента. Решение владельца принято осознанно и записано в правиле 2 CLAUDE.md. Средств обхода
антибот-проверок в коде нет: ни подмены отпечатка, ни прокси, ни имитации человеческого темпа.

**Что осталось на живой прогон.** Селекторы формы входа и мастера публикации, загрузка файлов,
выемка ссылки на пост. Первый прогон почти наверняка потребует правки одного-двух селекторов —
для этого они и вынесены списками вариантов в отдельный файл, а каждый сбой пишет скриншот
в `IG_SHOTS_DIR`. Порядок запуска — в конце спеки.
