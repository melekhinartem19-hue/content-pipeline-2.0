# 15 — Монтаж на ноуте клиента (локальный CC) + автозалив в очередь VPS

**What to build:** Пайплайн монтажа на ноутбуке клиента: локальный Claude Code (скиллы `hyperframes` + `hyperframes-cli` + `motion-graphics` / `embedded-captions` / `general-video` / `remotion-to-hyperframes`) собирает из реальных клипов лёгкий Reels и сам заливает готовый ролик в очередь согласования на VPS. Сырое видео НЕ идёт через бота (лимит Bot API 20 МБ) — монтаж только локальный. Ставится отдельно на машину клиента, не часть VPS-деплоя.

**Blocked by:** 07 — Очередь согласования + кнопки; 12 — IG-публикация (путь Reels).

**Status:** done (08.09.2026) — код и инструкции готовы; живьём проверяется на ноуте и VPS клиента
