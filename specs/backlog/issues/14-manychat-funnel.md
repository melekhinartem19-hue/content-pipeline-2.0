# 14 — ManyChat-воронка: 3 ключа → 3 PDF-ссылки

**What to build:** Инста-воронка через ManyChat (не через сырой API). 3 кнопки/ключа (без ИИ-классификации) сопоставляют выбранную тему с её PDF-ссылкой (Nginx-статика) или уводом в Telegram. Файл-PDF в самом IG-DM технически невозможен → отдаём ссылкой.

**Blocked by:** 13 — Презентатор: 3 PDF.

**Status:** done по коду (07.09.2026) — spec [../../manychat-funnel.md](../../manychat-funnel.md).
Живьём проверяется только на аккаунте клиента (ManyChat Pro + подключённый Instagram).

- [x] Матчинг темы — ровно 3 кнопки/ключа, без ИИ-классификации (`keyword`/`button` в конфиге; два одинаковых ключевых слова — ошибка конфига)
- [x] Каждый ключ → соответствующая PDF-ссылка (Nginx) или увод в Telegram (`fallbackTelegram`, когда ссылки нет)
- [x] Ведём через ManyChat, а не через сырой инста-API; в DM отдаём ссылку, не файл
- [x] Ключ/аккаунт ManyChat только в `.env` (`MANYCHAT_TOKEN`); тексты и ключи — в видимом `manychat/funnel.json`
- [x] Демо/конфиг: 3 ключа корректно ведут на 3 разных PDF (`/воронка тест <ключ>`, проверено в `smoke-manychat`)
- [x] Короткий spec воронки положен в `specs/manychat-funnel.md`

## Как сделано

Диспетчер **пишет** три публичные ссылки в bot-поля ManyChat (`pdf_<ключ>`) через
`POST /fb/page/setBotFieldByName`, а флоу с тремя кнопками собирает человек в UI один раз: API
ManyChat не умеет создавать флоу. Точные имена полей, подписи кнопок и тексты печатает команда
`/воронка настройка` в топике Презентатора. Входящих вебхуков и открытых портов нет — директ
работает, даже когда диспетчер лежит.

Команды: `/воронка` (состояние), `/воронка настройка`, `/воронка синх`, `/воронка тест <ключ>`.
После успешной сборки `/пдф` синхронизация запускается сама, если задан `MANYCHAT_TOKEN`.
Код: `dispatcher/src/funnel/reply.js` + `dispatcher/src/funnel/manychat.js`, миграция
`008_funnel_manychat` (что и когда записали в ManyChat → детект расхождения со статикой).
