# `render/` — визуал конвейера

Здесь текст агента превращается в **готовые файлы**:

- спецификация Дизайнера («слайд 1: заголовок, текст, визуал») → **PNG** каруселей и обложек (T10);
- структура Презентатора («страница 1: заголовок, текст, визуал») → **PDF-лид-магнит A4** (T13).

Модуль самостоятельный: он ничего не знает про Telegram, базу и `claude -p` — на входе текст, на
выходе файлы. Всё телеграмное живёт в диспетчере
([dispatcher/src/render/visuals.js](../dispatcher/src/render/visuals.js) для картинок,
[dispatcher/src/funnel/pdf.js](../dispatcher/src/funnel/pdf.js) для PDF).

Полное описание: [specs/render-visuals.md](../specs/render-visuals.md) (картинки) и
[specs/presenter-pdf.md](../specs/presenter-pdf.md) (PDF).

## Быстрый старт

```bash
cd render
npm install        # playwright-core (браузер НЕ скачивается — берётся уже установленный)
npm run demo       # пример карусели → render/out/*.png, открой и посмотри
npm run demo:pdf   # пример лид-магнита → render/out/demo.pdf
```

Свою спецификацию (например, скопированный из топика ответ Дизайнера) можно прогнать так:

```bash
node demo.mjs путь/к/спецификации.txt
```

## Как поменять внешний вид

**Вёрстку кадра** — в [templates/slide.html](templates/slide.html), **вёрстку листа PDF** — в
[templates/pdf.html](templates/pdf.html). Это обычный HTML с CSS: отступы, типографика, оформление
ролей `cover` / `body` / `cta`. Трогать JS для этого не нужно.

**Цвета, шрифт и подпись** — в [brand-brain/08-visual-style.md](../brand-brain/08-visual-style.md).
Это слот «мозга бренда», который заполняет клиент; код читает из него строки `Фон:`, `Текст:`,
`Акцент:`, `Шрифт:`, `Подпись:`. Пока слот пуст, слайды рендерятся нейтральной тёмной темой — это
ожидаемо, а не поломка.

## Что здесь лежит

| Файл | Зачем |
|---|---|
| [index.js](index.js) | публичный вход: `renderDesign()` — спецификация → PNG |
| [spec.js](spec.js) | разбор ответа Дизайнера на слайды |
| [theme.js](theme.js) | тема из brand-brain, контраст, шрифты |
| [html.js](html.js) | подстановка в шаблон, кегли по длине текста, мотивы-подложки |
| [templates/slide.html](templates/slide.html) | **вёрстка кадра 1080×1350** |
| [browser.js](browser.js) | поиск и запуск headless Chromium |
| [pdf.js](pdf.js) | разбор структуры Презентатора, вёрстка листа, печать в PDF |
| [templates/pdf.html](templates/pdf.html) | **вёрстка листа A4** (794×1123 px) |
| [templates/pdf-page.html](templates/pdf-page.html) | разметка одной страницы документа |
| [demo.mjs](demo.mjs) | посмотреть картинки глазами, без ботов и без claude |
| [demo-pdf.mjs](demo-pdf.mjs) | то же для PDF |

Рядом с картинками кладётся `slides.json` — разобранная спецификация и применённая тема; по нему
собирается IG-карусель (T12). Рядом с PDF так же ложится `<имя>.pdf.json` — разобранная структура
документа: воронке (T14) не нужно открывать файл, чтобы узнать заголовок и число страниц.

## Требования

Node 20+ и **любой установленный Chromium/Chrome**. Модуль находит его сам: кэш playwright,
системный Chrome, на Windows ещё Edge, на Linux `/usr/bin/chromium`. Если браузер лежит
нестандартно — `RENDER_BROWSER=/полный/путь` в `dispatcher/.env`.

На VPS (Linux) нужны ещё шрифты с кириллицей, иначе слайды выйдут квадратиками:

```bash
sudo apt-get install -y chromium fonts-dejavu fonts-noto-core
```

## Чего этот модуль не делает

Не рисует иллюстрации. Поле `Визуал:` у Дизайнера — идея кадра словами; из неё берётся только
**мотив** (геометрическая подложка: сетка, волна, дуга, столбцы, пятно), чтобы слайды одной
карусели не выглядели одинаково. Рендер типографский. Генерация настоящих иллюстраций — отдельная
история, в T10 её нет.

Не делает видео. Видео — это HyperFrames и монтаж на ноутбуке клиента (Фаза 4, T15).
